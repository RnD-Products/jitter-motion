# Jitter motion workflow

Rules, skills, workflow notes and helper tools for Jitter (jitter.video) animation work with Claude Code or other AI agents.

- [AGENTS.md](AGENTS.md): the rules (read first).
- [WORKFLOW.md](WORKFLOW.md): the detailed how-to-work guide, Jitter API notes and recipes.
- [JITTER-MCP.md](JITTER-MCP.md): how the Jitter MCP connector works (tools, read and write API, examples).
- [skills/jitter-motion-styles](skills/jitter-motion-styles/SKILL.md): the five motion styles (Bold, Playful, Elegant, Cinematic, Soft).
- [skills/jitter-shared-element-showreel](skills/jitter-shared-element-showreel/SKILL.md): universal workflow for multi-frame stories where one element travels through every frame (e.g. Figma → Webflow → Live).
- [skills/README.md](skills/README.md): index of all skills and how to add a new one.
- [tools/](tools/): Swift scripts to read reference videos (info and contact sheets).
